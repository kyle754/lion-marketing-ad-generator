# Lion Marketing Canva handoff

The generator already creates finished PNGs. Use this handoff when the team also wants editable
Canva templates or wants to use Canva Bulk Create.

## Bulk Create data

After generation, upload `3-OUTPUT/canva_bulkcreate.csv` to Canva Bulk Create. Its columns match
the editable text fields in the included designs:

- `eyebrow`
- `hook`
- `body`
- `cta`
- `stat`
- `stat_label`

The `designs` column is useful for routing and can be left unconnected in Canva.

## Canva template sizes

Build each design at:

- 1200×628 for landscape ads
- 1080×1080 for square placements
- 1080×1350 for portrait feed placements

For the portrait version, keep the logo and important copy within a centered 1080×1080 safe area
where possible.

## Included design directions

### Corporate

White editorial layout with Lion orange and gold accents. It pairs a clear campaign message with a
bold proof point. Use it for strategic, trustworthy, or conversion-focused creative.

### Bold

High-contrast gradient layout with centered copy, a gold CTA, and a subtle grid. Use it for short,
direct paid-social messages.

### Report

Dark performance-marketing layout with a white campaign snapshot card. Use it for case studies,
proof points, lead-generation offers, and reporting-led messages.

## Recommended Canva build order

1. Add the official Lion Marketing brand kit.
2. Rebuild one 1200×628 design and connect its text fields to Bulk Create.
3. Duplicate it to square and portrait sizes.
4. Check long and short sample rows before publishing the template.
5. Lock backgrounds, decorative elements, and logo placement.
6. Leave only campaign copy fields editable for day-to-day users.
